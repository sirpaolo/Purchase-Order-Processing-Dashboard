# 📊 Purchase Order Processing Report | Power BI Dashboard

## Overview

This Power BI dashboard provides an interactive analysis of **Purchase Order (PO) processing performance** over a two-month period (March–April). It is designed to help monitor operational efficiency by tracking weekly purchase order volumes, identifying performance trends, and comparing monthly outputs.

The dashboard enables users to quickly understand processing performance through key metrics, visual trends, and interactive filters.

## Dashboard Features

### 📈 Key Performance Indicators (KPIs)

* **Total POs Processed:** 158
* **Highest Weekly Output:** 26 POs
* **Average Weekly PO:** 15.80

### 📊 Weekly Purchase Order Trend

* Compares weekly PO processing between **March** and **April**
* Area chart highlights processing trends and weekly fluctuations
* Helps identify peak and low-performing weeks

### 🍩 Monthly Distribution

* Donut chart showing the percentage of purchase orders processed by month
* Provides a quick comparison of monthly workload distribution

### 📋 Detailed Weekly Table

* Displays:

  * Month
  * Week
  * PO Count
* Includes total processed purchase orders for validation

### 🎛 Interactive Filter

* Month slicer allowing users to:

  * View all months
  * Filter only March
  * Filter only April

## Insights

* Total of **158 purchase orders** were processed during the reporting period.
* **Week 3 of April** recorded the highest weekly output with **26 POs**.
* April contributed approximately **66%** of the total purchase orders, while March accounted for **34%**.
* The dashboard allows users to monitor operational trends and evaluate weekly processing performance.

## Tools Used

* **Microsoft Power BI**
* Power Query
* DAX (Data Analysis Expressions)
* Interactive Visualizations
* KPI Cards
* Area Chart
* Donut Chart
* Table Visual
* Slicers

## Purpose

This dashboard demonstrates how Power BI can transform operational purchase order data into meaningful insights, helping stakeholders monitor processing efficiency, identify trends, and support data-driven decision-making.
